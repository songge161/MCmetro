# Licence decision

Status: `pending final legal review`.

The repository's original planner code and documentation are intended to be released under MIT unless a later decision records otherwise. This file is a decision boundary, not a grant of rights to third-party data or Minecraft assets.

Rules for the project:

- synthetic sample data stays clearly labelled as synthetic;
- OSM data requires ODbL compliance and attribution;
- PLATEAU terms must be checked per dataset and municipality/version;
- N02 and other Japanese government data must follow the specific dataset terms and attribution instructions;
- MTR, Station Builder, mcbuild, Arnis and plateau2minecraft code/assets are not copied into this repository without checking their exact licence and notices;
- Minecraft/Mojang assets and mod files are not redistributed by the offline planner;
- every imported dataset must carry URL, revision/date, checksum where practical, CRS and licence into provenance metadata.

See [docs/research/SOURCES.md](docs/research/SOURCES.md) for the first source register.
